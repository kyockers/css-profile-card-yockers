Reflection:
I had a lot of fun making this! I didn't find any of the CSS hard to use, necessarily, but I definitely spent the most time on the text styling. I haven't used rem before (we didn't cover that in my HTML 1 class), so I just played with it until it looked like I wanted it to. The visual playground is surprisingly easy to use! I like that it explains how and why things work. External CSS is far superior to inline CSS (in my humble opinion). I get confused when there's a lot of styling in HTML. It's WAY too easy to forget things, like closing tags, and it gets hard to keep track of what styling is being used where. It also makes it impossible to change styling on multiple items at once, so there's a lot more room for error. I like being able to keep everything organized and labeled!
